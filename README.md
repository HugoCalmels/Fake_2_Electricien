# FakeElec

Site d'un électricien fictif à Toulouse : 25 pages, design libre, des câbles qui alimentent chaque section.
Démo, faux client.

[Site](https://fakeelec.netlify.app/) · [Captures et présentation](https://hugo-calmels.fr/fr/sites-web/site-statique)

## Fonctionnalités

- 25 pages pré-générées en HTML, sans base de données ni CMS
- Lighthouse 100 en performance, accessibilité, bonnes pratiques et SEO
- Responsive

## Stack

- Next.js 15, React 19, TypeScript, Tailwind CSS 4 — Netlify

## Lancer en local

```bash
npm install
npm run dev
```
